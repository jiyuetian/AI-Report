## 复查发现（本项核心价值）
不只是"有个占位 Alert"，而是挖出**设置页是全站唯一零 API 的 Tab**，且含一条**谎报**：
- 其它 6 个 Tab 都取真数据（`/admin/overview|users|roles|audit` 等），唯独设置页 4 条状态全硬编码；
- **`LLM网关: 已启用` 写死** —— 而后端 `llm_reachable` 实际可能 false（沙箱就是）。这与刚做完的 2.1 AI 鉴定 / 2.4 绿灰标"不可达就诚实显示"**直接自相矛盾**；
- Alert 声称"配置中心已实现（M2-01）"，但全站检索 `配置中心` 只命中这一行 → 失效声明。

## 实现要点
- LLM 网关 → 实时 `GET /health`，**三态**（可达/不可达/未知），请求失败显示"未知"而非默认"已启用"
- 配置版本/审计日志/自动备份 → `<Tag>即将上线</Tag>`，删除假值
- 失效 Alert → 改为如实说明"仅主题配置为真实可操作项"
- 角色页 Alert 已是诚实披露（"将在多用户版本开放"）→ 保留，符合"标注"要求
