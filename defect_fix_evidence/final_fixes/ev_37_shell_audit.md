## 二、但复查发现**同文件残留一个真空壳**：「对话历史」Modal

### 三宗罪
1. **假数据**：`dataSource={historyFiltered}`，源头是 :43 写死的 `mockHistory`（4 条编造的对话：标题/时间/摘要全为常量），与真实会话无任何关联。
2. **假动作（最严重）**：删除按钮 `onClick={() => message.success('已删除')}` —— **弹"已删除"但数据纹丝不动**（本地常量数组，删不掉，列表立刻原样显示）。点一次骗一次。
3. **右侧「导出」已正确 disabled**，唯独「删除」漏网 —— 同一行两个按钮标准不一致。

> 这与本项目"诚实、不谎报"的主线直接冲突（参考 2.1 半空壳鉴定、2.4 灰标、3.6 去假值）。

## 三、修复（`DashboardOps.tsx` 单文件）

### 1. 假删除 → 禁用 + 标注（与右侧「导出」一致）
```diff
- <Button key="d" size="small" type="text" danger onClick={() => message.success('已删除')}>删除</Button>
+ <Tooltip key="d" title="删除（即将上线）">
+   <Button size="small" type="text" danger disabled onClick={() => message.success('已删除')}>删除</Button>
+ </Tooltip>
```
> 保留 `onClick` 只为行为一致（disabled 后不可达）；核心是**不再让用户点出一个假的"已删除"**。

### 2. 假数据如实标注（新增 Alert）
```diff
+ <Alert type="warning" showIcon style={{ marginBottom: 12 }}
+   message="以下为演示样例数据，真实对话记录的持久化即将上线。" />
```
