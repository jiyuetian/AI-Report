# 图标与图例编排规范（Icon & Legend Guard）

> 作用：约束 AI 为 KPI / 图表 / 卡片选用图标、趋势箭头、图例与风险用色，使其语义明确、契合中国商务习惯、不喧宾夺主。
> 这是**全局护栏**，与 system / accuracy / ui_style 同级，AI 生成任何前端表达都必须遵守。

## 一、KPI 图标语义
- 图标须与指标含义**一一对应、语义明确**：金额类用 ￥/硬币、笔数/数量类用清单/计数、比率类用百分比环、时间类用时钟/日历。
- 同一看板内同义指标用**同一种**图标，避免一个"在保余额"用硬币、另一个"代偿金额"也用硬币造成混淆；确需区分时以颜色/形状差异强化。
- 禁用与数据无关的吉祥物图标、无意义装饰图标；禁用 3D 拟物图标（与 AntD 扁平风冲突）。

## 二、趋势箭头规范
- 同比/环比方向用 **↑ / ↓** 标注，并紧跟时间区间（如「↑ 同比 2025Q1」「↓ 环比上月」）。
- 方向配色遵循 A 股习惯：**上涨 / 正向 / 超额 → 红色**；**下跌 / 负向 → 绿色**；中性变化用灰。
- 无显著变化（|Δ| 极小）用 → 或「持平」，不强行染色。

## 三、图例规范
- 分类图（饼图/柱状图/堆叠图）图例须与分类**取值一一对应**，不遗漏、不重复、不合并同类不同名。
- 图例文字直接用字段真实取值（如「已婚」「未婚」），不改写为抽象词；取值过长时截断并加 tooltip 全称。
- 多序列图（折线/分组柱）用颜色 + 形状双重区分，避免仅靠颜色（色盲友好）。

## 四、风险用色（三档，禁用灰阶表达风险）
- **红（高危）→ 橙（中危）→ 黄（低危）** 三档梯度；风险等级一律用此梯度，禁用灰阶/黑白表达风险高低。
- 风险阈值（如逾期率>5% 为红）由业务口径确定，AI 不得自造阈值；无明确口径时标注「风险等级依据待确认」。

## 五、禁忌
- 不堆 emoji 装饰；不把图标当背景水印；不擅自加企业 LOGO 或标语图标。
- 不在非风险指标上滥用红绿色（红绿仅用于「涨跌/风险」语义，普通对比用中性蓝灰）。
