# 行业指标处理规范（Industry Metrics Guard）

> 作用：约束 AI 在选指标、写标题、做聚合时对**行业口径与单位**的处理，避免口径错配、单位混乱、比率误聚合。
> 这是**全局护栏**，与 system / accuracy / ui_style 同级，AI 生成任何分析表达都必须遵守。

## 一、风控领域口径（担保 / 信贷 / 房贷）
- **逾期率** = 逾期金额 ÷ 在保余额；**不良率** = 不良余额 ÷ 在保余额；**代偿率** = 代偿金额 ÷ 在保余额。
- 分子分母必须**同源、同期**（同口径数据集、同统计时点），不得跨表拼凑。
- 上述均为**比率指标**，只能按 `avg`（平均值）汇总，**严禁 sum/求和**（比率求和无业务意义）。
- 率类指标不要和它自己的分量金额列（分子/分母）放进同一张图重复表达。

## 二、财务领域口径
- 收支结构看**收入构成 / 支出构成 / 净额（收入−支出）**；关注同比、环比与结构性占比。
- 同一看板金额单位统一（万元 / 亿元），跨量级用万/亿归一，不混用「元/万/亿」。
- 利润率 = 利润 ÷ 收入，同样为比率类，只能 avg。

## 三、通用口径（所有领域适用）
- **环比** = 本期 vs 上一相邻周期（上月/上季）；**同比** = 本期 vs 去年同期。必须明确标注时间区间（如「同比 2025Q1」）。
- 比率本身标 `%`；**差值变化标 `pp`（百分点）**，不得把「上升 2 个百分点」写成「上升 2%」。
- **金额单位换算**：按量级自动选用 万 / 亿 并标注（如「万元」「亿元」），不堆长数字；同一看板单位一致。
- **同比/环比方向箭头**（见 icon_arrangement）：↑/↓ 配合红涨绿跌。

## 四、聚合与字段红线
- 所有 x_field / y_field / category_field / value_field 必须是数据集**真实存在的原始字段名**，严禁臆造（如 `逾期率_分桶`、`status_flag`）。
- 比率类字段聚合口径强制 `avg`；连续数值字段可直接引用原字段名做分桶/分组，不擅自构造派生列。
- 不确定某指标的权威口径时，**声明置信度 / 标注「口径待确认」**，不得臆造分母或分子。
