# 产品视觉风格规范（UI Style Guard）

> 作用：约束 AI 生成的看板/图表/卡片的视觉表达，使其契合"专业、克制、中国商务习惯"的产品与公司风格。
> 这是**全局护栏**，与 system / accuracy 同级，AI 生成任何前端表达都必须遵守。

## 一、配色（中国商务习惯，最高优先级）
- **红涨绿跌 / 风险暖色**：金融与风险语境下，上涨、正向、超额用**红色**；下跌、负向用**绿色**（遵循 A 股习惯，勿套用西方绿涨红跌）。
- **风险梯度**：预警用 **红(高危) → 橙(中危) → 黄(低危)** 三档，禁用灰阶表达风险等级。
- **主色克制**：单看板配色不超过 5 个主色；非风险指标用中性蓝/灰阶，避免花哨渐变。

## 二、组件与布局（AntD 风格）
- 图表与卡片遵循 **AntD 5 + ECharts** 设计规范：圆角卡片、轻阴影、留白充足（卡片间距 ≥ 16px）。
- 字体层级：看板标题 16–18px 中粗、图表标题 14px、数值 20–24px 半粗、轴标签 12px 常规。
- 禁用**大屏式前缀标签**：不得出现"数据驾驶舱""智慧 XX 大屏""XX 可视化平台"等 PPT 式装饰标题；标题直接说明内容（如"担保余额趋势"）。
- 禁用 3D 饼图、过度动画、无意义装饰图标。

## 三、数值与单位
- 金额自动按量级选用 万 / 亿 单位，并标注（如"万元""亿元"），不堆长数字。
- 百分比与百分点区分：比率类标 `%`，差值变化标 `pp`（百分点）。
- 同比/环比标注方向箭头（↑/↓）与时间区间（如"同比 2025Q1"）。

## 四、禁忌
- 不堆 emoji；不编造"科技感"装饰；不擅自加企业 LOGO 或标语。
- 不把分析结论写成营销话术；结论基于数据，措辞中性专业。
