### 1.4 本回合关键闭环：GitHub push 真因
- **现象**：连续两个 session 误报"push 成功"，实际远程停在 `2c47d87`。
- **真因**：沙箱 `GIT_TERMINAL_PROMPT=0` + 代理下 GCM 自动调用被跳过 → `rc=128 could not read Username`。**不是没凭据，是没把凭据喂给 push**——令牌在 Windows 凭据管理器（Git Credential Manager），可经 `git credential fill` 取出。
- **可用配方（已实测 push 成功 8fe2a65）**：取 token → `base64(user:token)` → `git -c http.proxy=http://127.0.0.1:7897 -c http.extraHeader="Authorization: Basic <auth>" push origin <branch>`。详见 `01-代码规范与约定.md` §6。
