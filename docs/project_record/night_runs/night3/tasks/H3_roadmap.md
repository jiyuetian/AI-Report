## 本项最大产出：纠正了执行顺序

我最初按用户给的顺序写方案（O→P→Q→B），**调研完后发现顺序错了**：

| 顺序 | 理由 |
|---|---|
| **B 第一** | 消除已实测确认的 5 分钟卡死（180s+120s），与度量无关，可独立先做 |
| **O 第二** | 度量基础 —— 没有 O 就无法证明 Q 有没有用 |
| **Q 第三** | 便宜（材料链路上已算出），但**必须先有 O 才能 A/B 验证** |
| **P 第四** | 最贵（4~5h）但差异化最强 |

**关键论证**：Q 的核心假设"注入画像能让 LLM 选得更准"，
**只有靠 O 的埋点（一次通过率/重试次数）才能验证**。先做 Q 就只能说"我觉得变好了"——
这正是我在 SELF_REVIEW_1 里批评过的做法。
